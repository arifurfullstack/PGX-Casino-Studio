12. FIVE-DAY RESERVATION RULES

Once payment is successfully completed:

1. Generate a unique reservation ID.
2. Record the successful $500 payment.
3. Save the selected casino design and add-ons.
4. Save the original package price.
5. Apply and lock the 5% discount.
6. Save the discounted package total.
7. Record the reservation start time.
8. Set the expiration to exactly 120 hours later.
9. Notify the admin.
10. Send a reservation confirmation to the customer.

Reservation Statuses

The system must support:

- Pending Payment
- Active Reservation
- Agreement Completed
- Expired
- Refund Pending
- Refunded
- Cancelled

If the Customer Completes the Deal

The admin changes the reservation status to Agreement Completed.

The $500 reservation fee is credited toward the final discounted package price.

The reservation is then converted into a confirmed customer project.

If the Customer Does Not Complete the Deal

If no agreement is completed within the five-day period:

1. The reservation expires.
2. The design hold is released.
3. The 5% discount expires.
4. The system initiates a full refund of the $500 fee.
5. The customer receives an email confirming that the refund has been initiated.
6. The admin dashboard records the refund status.

The website must not state that money has been returned until the payment provider confirms the refund.

The customer must not lose the reservation fee simply because no agreement was completed.

Important

The reservation must not be advertised as exclusive ownership of a casino design unless ALL I GAMING can genuinely guarantee exclusivity.

If designs are sold to multiple buyers, the wording should describe a reserved configuration and price rather than exclusive ownership.
